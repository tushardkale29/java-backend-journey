# Java Backend Developer Journey

A complete hands-on journey to build strong Java backend development
skills from fundamentals to production-ready applications.

## Goal

Build practical skills equivalent to a strong Java backend developer
with around 4 years of real-world experience.

## Technology Stack

- Java 21
- Maven
- Spring Boot
- Spring Framework
- REST APIs
- JPA / Hibernate
- Spring Security
- SQL
- Microservices
- Kafka
- Docker
- Git / GitHub
- CI/CD
- JUnit / Mockito
